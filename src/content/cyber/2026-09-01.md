# MailVet

**Author**: [Ayushman Chhabra](/#/blog/author/Ayushman%20Chhabra)

**Published**: 2026-09-01

**Modified**: 2026-09-01

MailVet identified disposable emails. The service is exposed as a single API endpoint which gives a lot of flexilibity:

1. Place the API call as a validation check on user signup before the request data hits the database.
1. Run a cron job to scan recent signups 24-48 hours later to identify potential disposable emails, send a verification email. If response is `250 OK` wait for 24-48 hours, on no response delete the account. If response is `550 User unknown`, delete it anyway.
1. Plug into an SMTP server, create a rule to send emails from all temporary emails to Junk.

Give is a try at [https://verify.asyncawake.studio](https://verify.asyncawake.studio).
