# CVE-2026-22226

**Author**: [Ayushman Chhabra](/#/blog/author/Ayushman%20Chhabra)

**Published**: 2026-07-30

**Modified**: 2026-07-30

During an authorized engagement, I came across a TP Link router which was vulnerable to [`CVE-2026-22226`](https://www.cve.org/CVERecord?id=CVE-2026-22226) (Authenticated LAN-side OS Command Injection in the VPN Client of TP-Link Archer Wi-Fi routers). After going through the vulnerability description and exploit code, I discovered that the proof of concept was for the EU router while my target was a US target. In the EU router, all one had to do was be in the Wi-Fi network, run Wireshark and intercept all HTTP traffic going to the router, usually at `192.168.1.1`. In my case, since it was a grey box engagement, the password was already known.

On blindly running the exploit code, it failed, so I used Burp Suite to see what's going wrong. Every request was signed with a `sign` and `data` parameter.
